###How to Launch BoxVault

Install Python dependencies:
    bash
    pip install -r requirements.txt
Initialize Reflex:
    bash
    reflex init
Start the application:
    bash
    reflex run

On first launch, navigate to http://localhost:3000:

Enter admin as the username or click "Set Admin Password Now".

Set your master password and log in. The Administrator account is activated and ready to manage users and inventory.
